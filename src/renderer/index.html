欢迎使用 Input Helper

1. 摆放窗口：按住顶部标题栏把窗口拖到任意位置，拖拽边缘可改变大小。

2. 自动隐藏：鼠标一移开，窗口立即完全隐藏，不留痕迹。

3. 唤出：鼠标移回原位置即可恢复；按 Ctrl+Alt+E 也能随时唤出。

4. 老板键：Ctrl+Alt+Q 一键彻底隐藏，再按恢复。

5. 书架：打开即进入你的书架；点标题栏「书城」可切换到书城找书。

6. 设置：标题栏「⚙」里可切换隐藏模式、淡化程度和窗口缩放。
