# Input Helper（摸鱼阅读器 v2）

一个运行在 Windows 上的轻量桌面阅读器外壳：内嵌番茄小说官方网页版，**窗口可自由拖到任意位置并记住**，鼠标移开后就地淡出、移回恢复；老板键一键完全隐身，托盘与进程名均伪装为中性工具。

> 说明：本程序只是官方网页 `fanqienovel.com` 的容器，**不破解、不绕过付费或广告**，阅读请遵守网站条款与你的单位规定。

## 功能
- **自由摆放（默认）**：按住标题栏把窗口拖到任意位置，位置自动记住，重启后仍在原处。
- **就地淡出隐藏**：鼠标移开约 0.5 秒，窗口淡成极低透明度（默认 6%，留个锚点方便你找到），点击穿透不影响下层窗口；鼠标移回那块区域即恢复清晰。
- **老板键隐身**：`Ctrl+Alt+Q` 一键彻底隐藏（窗口消失 + 托盘改名换图标），再按恢复。
- **登录态持久化**：登录一次番茄账号，重启后书架与阅读进度保留。
- **两种模式**：自由摆放（就地淡出）/ 贴边隐藏（缩到边缘露细线），托盘菜单或标题栏按钮可切换。
- **首次启动提示**：第一次打开会正常显示并弹出操作说明，点"知道了"或 15 秒后进入正常逻辑。
- 配置可改：淡出透明度、动画时长、宽限期、轮询间隔、老板键、窗口尺寸等。

## 安装与运行
- **安装包**：运行 `dist/Input Helper Setup 1.0.0.exe`，按提示安装。
- **便携版**：直接运行 `dist/InputHelper-Portable.exe`，无需安装。
- **源码运行**：`npm install` 后 `npm start`（需 Node 22+）。

首次启动会显示窗口并弹出操作说明；如需书架同步，在窗口内用手机号或抖音扫码登录一次即可。

## 快捷键 / 操作
| 操作 | 方式 |
|---|---|
| 移动窗口 | 按住顶部标题栏拖动（自由摆放模式） |
| 唤出窗口 | 把鼠标移回窗口所在位置，自动恢复清晰 |
| 淡出隐藏 | 鼠标移开 0.5 秒自动淡出，或点标题栏「收起」 |
| 完全隐身 / 恢复 | `Ctrl+Alt+Q`（若被占用，托盘菜单里改键） |
| 切换定位模式 | 标题栏「自由摆放/贴边模式」按钮，或托盘菜单 |
| 退出 | 托盘菜单「退出」，或标题栏 × |

## 配置文件
位置：`%APPDATA%/Input Helper/config.json`（资源管理器地址栏输入该路径可打开）。

```jsonc
{
  "mode": "free",             // free=自由摆放就地淡出（默认） | edge=贴边隐藏
  "windowX": null,            // 你拖动后的窗口位置，null=首次居中偏上
  "windowY": null,
  "idleOpacity": 0.06,        // 淡出后保留的透明度锚点，0=完全隐形（更难找）
  "firstRunShown": false,     // 首次提示是否展示过
  "windowWidth": 460,
  "windowHeight": 760,
  "edge": "right",            // edge 模式下的贴边方向：right/left/top/bottom
  "revealPx": 6,              // edge 模式隐藏时露出像素
  "triggerBandPx": 18,        // edge 模式边缘触发带宽度
  "graceMs": 500,             // 鼠标移开后多久隐藏（毫秒）
  "animationMs": 220,         // 淡入淡出动画时长
  "pollMs": 60,               // 鼠标轮询间隔
  "bossKey": "Ctrl+Alt+Q",
  "normalTrayLabel": "输入助手",
  "stealthTrayLabel": "系统服务",
  "openAtLogin": false,
  "cleanMode": false,
  "url": "https://fanqienovel.com/"
}
```
改完配置需重启程序生效（部分几何项在菜单切换时会即时刷新）。

> `cleanMode` 为预留实验项，当前版本未启用任何内容过滤逻辑（本程序不改动番茄网页内容）。保持 `false` 即可。

## 清除登录态
关闭程序后删除目录：`%APPDATA%/Input Helper/EBWebView`（或整个 `userData` 下与 `persist:fanqie` 相关的缓存）。下次启动即为未登录。

## 常见问题
- **双击后看不到窗口**：v2 首次启动会正常显示窗口；之后窗口以 6% 透明度留在你上次摆放的位置，把鼠标移回那里即可唤出。想要更明显就把 `idleOpacity` 调到 0.15 左右。
- **老板键没反应**：多半被其他软件占用。点托盘图标 →「老板键…」换成 `Ctrl+Alt+W`。
- **任务栏看不到图标**：这是设计如此（跳过任务栏），程序常驻托盘，隐身时也靠托盘恢复。
- **网页打不开/风控**：在窗口内手动完成网站验证即可；本程序不自动化绕过任何验证。
- **公司电脑管控严格**：全局热键、置顶透明窗可能被安全软件限制，这属于环境限制，程序无法规避。
- **想换图标**：替换 `assets/icon.ico`（需含 256×256）后重新 `npm run build`。
