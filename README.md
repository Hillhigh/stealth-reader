# Input Helper（摸鱼阅读器 v6）

一个运行在 Windows 上的轻量桌面阅读器外壳：内嵌番茄小说官方网页版，**打开即进入你的书架**，像手机 App 一样继续阅读；标题栏可一键在「书架 / 书城首页」间切换，还能**一键重新登录/切换账号**。**内容自动适配窗口尺寸**，窗口可自由拖动、拖拽边缘缩放并记住；鼠标移开后**完全隐藏、不留痕迹**，移回原处即恢复；老板键一键隐身，托盘与进程名均伪装为中性工具。软件内置**设置面板**，可随时调节隐藏模式、淡化程度和窗口缩放。

> 说明：本程序只是官方网页 `fanqienovel.com` 的容器，**不破解、不绕过付费或广告**，阅读请遵守网站条款与你的单位规定。

## 功能
- **自由摆放**：按住标题栏把窗口拖到任意位置；开启缩放后拖拽窗口边缘可改变大小。位置和尺寸都会记住，重启后不变。
- **完全隐藏（默认无痕）**：鼠标一移开窗口，立即隐藏得一点痕迹都看不到（透明度 0%、点击穿透）；鼠标移回原位置即恢复。
- **内置设置面板**：标题栏「⚙ 设置」里可切换隐藏模式（就地 / 贴边）、调节淡化程度（0%~50%）、开关窗口缩放、开关开机自启，改动即时生效并自动保存。
- **老板键隐身**：`Ctrl+Alt+Q` 一键彻底隐藏（窗口消失 + 托盘改名换图标），再按恢复。
- **唤出快捷键**：`Ctrl+Alt+E` 随时强制唤出窗口（无痕模式下忘位置时的兜底）。
- **打开即进书架**：双击后直接进入 `fanqienovel.com/bookshelf`（你的书架），登录一次即可像手机一样继续阅读，不必每次从书城首页找书。
- **桌面版阅读（v5）**：番茄会把桌面窗口误判成手机端、只显示"下载 App"引导；程序自动给网址加 `force_mobile=0` 强制走桌面版，**书架、正文阅读全部正常，无需安卓模拟器**。
- **书架 / 书城一键切换**：标题栏「书城 / 书架」按钮一键往返，当前所在页会被记住，下次启动保持；站内点导航也不会退回下载页。
- **一键重新登录（v6）**：标题栏「登录」按钮清除当前登录态并打开首页，可扫码/手机号重新登录或切换账号。书架没同步最新书、提示"账号在别处登录"时用这个。
- **内容自适应尺寸（v6）**：番茄书架是固定宽度布局，程序会按窗口宽度自动缩放，让书架里的书完整显示不再被裁切；窗口拉大拉小会实时重算。阅读页本身是响应式的，保持原字号不受影响。
- **登录态持久化**：登录一次番茄账号，重启后书架与阅读进度保留。
- **启动即可见**：双击后窗口先正常显示约 2 秒（让你看到位置），随后鼠标一移开就隐藏；鼠标放上去随时显示。首次打开还会弹出操作说明。

## 安装与运行
- **安装包**：运行 `dist/Input Helper Setup 1.0.0.exe`，按提示安装。
- **便携版**：直接运行 `dist/InputHelper-Portable.exe`，无需安装。
- **源码运行**：`npm install` 后 `npm start`（需 Node 22+）。

首次启动会显示窗口并弹出操作说明；程序默认打开你的书架，在窗口内用手机号或抖音扫码登录一次，书架与阅读进度即可同步，之后免登录。

## 设置面板
点击标题栏「⚙ 设置」打开，包含：

| 设置项 | 说明 |
|---|---|
| 隐藏模式 | `就地隐藏`（原地消失，推荐）/ `贴边隐藏`（缩进屏幕边缘） |
| 淡化程度 | 0% = 完全无痕（默认）；调高到 5%~10% 可留一个淡淡的位置锚点 |
| 窗口可拖拽缩放 | 开启后拖拽窗口边缘可自由改变大小 |
| 开机自启 | 登录 Windows 后自动运行 |
| 恢复默认 | 一键还原上述设置 |

## 快捷键 / 操作
| 操作 | 方式 |
|---|---|
| 书架 / 书城切换 | 标题栏「书城 / 书架」按钮（按钮文字 = 点它将前往的页面） |
| 重新登录 / 切换账号 | 标题栏「登录」按钮 → 确认 → 在打开的页面扫码登录 |
| 移动窗口 | 按住顶部标题栏拖动 |
| 改变窗口大小 | 拖拽窗口边缘（需在设置里开启「窗口可拖拽缩放」） |
| 唤出窗口 | 鼠标移回窗口所在位置；或按 `Ctrl+Alt+E`；或单击托盘图标 |
| 隐藏窗口 | 鼠标移开立即隐藏（无延迟），或点标题栏「收起」 |
| 完全隐身 / 恢复 | `Ctrl+Alt+Q`（若被占用，托盘菜单里改键） |
| 切换定位模式 | 标题栏「自由摆放/贴边模式」按钮，或设置面板 |
| 退出 | 托盘菜单「退出」，或标题栏 × |

## 配置文件
位置：`%APPDATA%/Input Helper/config.json`（资源管理器地址栏输入该路径可打开）。一般直接用软件内的设置面板即可，无需手改。

```jsonc
{
  "mode": "free",             // free=自由摆放就地隐藏（默认） | edge=贴边隐藏
  "windowX": null,            // 拖动后的窗口位置
  "windowY": null,
  "windowWidth": 460,         // 窗口尺寸（拖拽缩放后自动更新）
  "windowHeight": 760,
  "idleOpacity": 0,           // 隐藏后的透明度；0=完全无痕（默认），0.06=留锚点
  "resizable": true,          // 是否允许拖拽边缘缩放
  "graceMs": 0,               // 鼠标移开后多久隐藏（毫秒）；0=移开立即隐藏
  "edge": "right",            // edge 模式下的贴边方向：right/left/top/bottom
  "revealPx": 6,
  "triggerBandPx": 18,
  "animationMs": 220,         // 淡入淡出动画时长
  "pollMs": 60,               // 鼠标轮询间隔
  "bossKey": "Ctrl+Alt+Q",
  "normalTrayLabel": "输入助手",
  "stealthTrayLabel": "系统服务",
  "openAtLogin": false,
  "cleanMode": false,
  "url": "https://fanqienovel.com/bookshelf?force_mobile=0",  // 默认打开你的书架（桌面版）
  "homeUrl": "https://fanqienovel.com/?force_mobile=0",       // 「书城」按钮跳转的书城首页
  "schemaVersion": 5
}
```
改完配置需重启程序生效（设置面板里的改动即时生效，无需重启）。

> `force_mobile=0` 是让番茄显示桌面版书架/正文的关键参数，删除后会退回"下载 App"引导页。程序在加载和站内导航时会自动补上，一般无需手动处理。

> 从旧版升级会自动迁移配置：`graceMs: 500 → 0`、`idleOpacity: 0.06 → 0`、旧默认首页 → 书架，以及首页/书架网址补 `force_mobile=0`，并写入 `schemaVersion: 5`，其它设置、窗口位置和尺寸不受影响。若你手动改过自定义网址，会原样保留。

> `cleanMode` 为预留实验项，当前版本未启用任何内容过滤逻辑（本程序不改动番茄网页内容）。保持 `false` 即可。

## 清除登录态
软件内点标题栏「登录」→ 确认即可清除并重新登录，无需手动删文件。也可关闭程序后手动删除目录：`%APPDATA%/Input Helper/EBWebView`。下次启动即为未登录。

## 常见问题
- **书架没有同步我最新加的书**：多半是登录态失效了（番茄同一账号在手机 App 登录后会把网页端挤下线，页面会提示"账号在其他地方登录"）。点标题栏「登录」重新登录一次，**用与手机完全相同的账号方式**（同手机号/同扫码授权），书架就会同步。另外，窄窗口下书架内容以前会被横向裁切，v6 已自动缩放让全部书籍显示出来。
- **书架文字太小**：内容按窗口宽度自动缩放，窗口越宽字越大。把窗口拖大一些即可；书城首页内容超宽，为保可读性设了最小缩放，允许少量横向滚动。
- **提示"下载番茄小说App / 暂无内容"**：这是番茄把桌面窗口误判成手机端所致。v5 已自动给网址加 `force_mobile=0` 强制走桌面版，正常应显示你的书架和正文；若仍看到下载页，点标题栏「重新加载」按钮即可。无需安装安卓模拟器。
- **登录后看不到书架**：程序默认打开的就是书架页 `bookshelf`；若停在了书城首页，点标题栏「书架」即可回去。首次使用请先扫码登录，书架内容才会同步显示。
- **正文显示成乱码/方块字**：这是番茄网页自身的字体加密，视觉渲染是正常的，不属于程序故障。
- **隐藏后找不到窗口**：默认完全无痕（透明度 0），把鼠标移回你摆放的位置即可唤出；实在找不到就按 `Ctrl+Alt+E` 或单击托盘图标。想留个视觉锚点，可在设置里把「淡化程度」调到 5%~10%。
- **双击后窗口一闪就没了**：这是正常的——启动时会先显示约 2 秒让你确认位置，随后鼠标不在窗口内就自动隐藏。把鼠标移到那个位置即可唤出。
- **老板键没反应**：多半被其他软件占用。点托盘图标 →「老板键…」换成 `Ctrl+Alt+W`。
- **任务栏看不到图标**：这是设计如此（跳过任务栏），程序常驻托盘。
- **网页打不开/风控**：在窗口内手动完成网站验证即可；本程序不自动化绕过任何验证。
- **公司电脑管控严格**：全局热键、置顶透明窗可能被安全软件限制，这属于环境限制，程序无法规避。
- **想换图标**：替换 `assets/icon.ico`（需含 256×256）后重新 `npm run build`。
